# Reichmann et al. — South America

This repository contains the R code and geographical data used to assess the effects of ALAN (artificial light at night) on landscape connectivity through network centrality metrics and to generate the manuscript figures.

## Workflow

Run the scripts in this order:

1. **Calculate J:** `01_local_community_size_J.R` calculates freshwater and LAND J from habitat areas and creates `M.SA.J` with all freshwater and LAND J columns and saves it as `M.SA.J.RData`.
2. **Add light pollution:** `02_light_pollution.R` joins the light pollution input table and adds `M.SA.J.LP`. The analyses select columns by name, so they do not depend on column positions.
3. **Networks and centrality metrics:** `03_network_centrality.R` builds connectivity networks and calculates in-degree, out-degree and betweenness centrality, with and without considering the impact of light pollution.
4. **Eigenvalues:** `04_eigenvalues.R` calculates landscape carrying capacity by ecoregion and adds the results to the results file.
5. **Ratios, maps and exports:** `05_export_maps.R` compares centrality metrics across scenarios and creates and exports the maps.

## Data

- `Paisaje_SA_EcoR_M_SA_J_LP.RData`: base geographical matrix `M.SA`, ecoregion boundaries and the raw light pollution table `LP_grid` (from `Grid_SA_umbral_2024.csv`). The light pollution data are stored separately from `M.SA`; scripts 01 and 02 prepare the combined matrix. `M.SA.J` and `M.SA.J.LP` are generated by scripts 01 and 02; they are not included in the initial file.

The results file (`Resultados_redes_D50.4.RData`) is not included in this repository. To run the maps without repeating the analyses, it is available upon request by email at [flor.reichmann@gmail.com](mailto:flor.reichmann@gmail.com).

The analyses include 52 ecoregions, with Patagonia and the Malvinas Islands treated separately. Ecoregion 351, which contains one cell, is excluded.

## How to use

Open `Reichmann_et_al_SA.Rproj` in RStudio and keep all files in the same folder.

To recalculate all results, follow the workflow above. Full calculations may require substantial memory and time.

If using the results file requested by email, run steps 1 and 2 first, then run the map script as needed. Some scripts use the same output filenames.

## Requirements

R packages: geosphere, sp, stars, sna, igraph, RSpectra, ggplot2, scales, sf, dplyr, readr and patchwork. The code was checked using R 4.5.2; the full model was not recalculated for every ecoregion.
